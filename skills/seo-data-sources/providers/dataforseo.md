# DataForSEO

仕様の正本: https://docs.dataforseo.com/v3/ 。
月額は無く、前払いした残高から使った分だけ減る。残高に期限は無い。

`seo-data-sources` のフォルダにあるスクリプトを使う。ほかの skill から呼ぶときは `../seo-data-sources/scripts/dataforseo.py`。

```bash
python3 scripts/dataforseo.py balance                          # 残高（無料）
python3 scripts/dataforseo.py volume "〈語1〉" "〈語2〉"          # 検索数と推移
python3 scripts/dataforseo.py volume --file words.txt
python3 scripts/dataforseo.py volume --monthly --file words.txt   # 月ごとの検索数も出す
python3 scripts/dataforseo.py serp "〈問い〉" --own 〈自社のドメイン〉   # 検索結果と AI による概要の引用元
python3 scripts/dataforseo.py serp "〈問い〉" --own 〈自社のドメイン〉 --text   # AI による概要の本文も出す
```

使った料金（ドル）は、出力の `# cost_usd=` に出る。

## 国と言語

日本・日本語が既定。変えるときは `--location 〈国の番号〉 --language 〈言語の記号〉` を、`volume` や `serp` の前に置く。値は Project 文書 `docs/seo-settings.md` に決めたものを使う。

国の番号と言語の記号は、公式の一覧（`https://docs.dataforseo.com/v3/keywords_data/google_ads/locations/` と `…/languages/`）で調べる。例: アメリカ・英語は `--location 2840 --language en`。

## 検索数と推移

出力はタブ区切りで、`keyword, volume, recent3_avg, trend, competition, competition_index, cpc_usd, bid_low_usd, bid_high_usd`。

- `volume`: 月間の検索数（Google 広告の数字）。空欄はデータなし。
- `recent3_avg`: 直近 3 か月の平均。
- `trend`: 直近 3 か月の平均 ÷ 12 か月の平均。1.3 以上で「伸びている」、0.7 以下で「減っている」。
- `competition` と `competition_index`: 検索広告の出稿の競合（LOW / MEDIUM / HIGH と 0〜100）。記事の順位の取りやすさではない。
- `cpc_usd`: 検索広告（リスティング）の平均クリック単価。`bid_low_usd` と `bid_high_usd` は、検索結果の上部に出すための入札の目安の下限と上限。**どれもドル**。円で伝えるときは、使った為替の値と日付を添える。空欄はデータなし。
- クリック単価が高い語は、広告主がお金を払ってでも取りたい語で、買う気のある検索が多い目安になる。検索数が小さくても、単価が高い語は記事の候補から外さない。
- **料金は 1 回ごとで、1 語でも 1,000 語でも同じ。** 検索数もクリック単価も同じ 1 回で返るので、追加の料金は無い。候補はまとめて 1 回で送る。料金の額は公式の料金表で確かめ、見た日付を付けて伝える。
- `--monthly` を付けると、月ごとの検索数（`monthly` 列、古い順）も出る。いちばん多い月や、最初と最後の月を見たいときに使う。月ごとの数字のために、もう 1 回呼ばない。
- 1 語は 80 文字まで、空白で区切って 10 語まで。超える語と、記号（`, ! @ % ( ) ? |` など）を含む語は、送らずに知らせる。長い問いは短い言い方に直して引く。
- 呼べるのは 1 分に 12 回まで。

### 数字の読み方

- 検索数は Google 広告が刻んだ値で返る（例: 390、880、1,600、2,900）。似た語は Google がまとめて同じ数字を返すことがある。同じ数字が並んだら、足し合わせない。
- 短い略語は、別の意味（製品の形、地名、店の名前、制度の名前）が混ざって大きく出る。「〜 対策」「〜とは」のように、意味が決まる語を足した言い方で比べる。
- 機能や製品の名前そのものは、使い方を探す人の数で、対策の需要ではない。
- 造語の長い言い方は、数字が返らないか、とても小さいことが多い。返らなければ「返らなかった」と書く。推測で埋めない。
- 単価（`cpc_usd`）が空でも、入札の目安（`bid_low_usd`・`bid_high_usd`）だけ出る語がある。その語は入札の目安で補って読む。検索数の小さい語は値がぶれ、上限が極端に大きくなることがある。絶対額ではなく、同じテーマの中の順で読む。
- 狭い分野の問いに「〜 ツール」「〜 料金」「〜 比較」「〜 会社」を機械的に足しても、多くはデータなしで返る。数字が出るのは、広い言い方のほうが多い。広い比較の語は単価が高くても、比較のメディアが強いので、記事の少ないサイトでは選ばない。
- 「〜 代行」は検索数も単価も大きく出ることがあるが、人に頼みたい意図で、自社の答えが合うかは検索結果を見るまで分からない。単価だけで上げない。

## ある問いの検索結果と、AI による概要の引用元

出力の先頭に、AI による概要が出たか（`ai_overview`）、引用元の数（`references`）、自社が引用されたか（`own_cited`）、通常の検索での自社の順位（`own_organic_rank`）が出る。続けて、引用元（`引用`）、通常の検索結果の上位 10 件（`検索`）、関連する質問（`質問`）が並ぶ。

- `--own` には自社のドメインを渡す（`example.com`。`https://` や `www.` が付いていてもよい）。下位のドメインも自社として数える。
- **`domain` が「不明」の行がある。** Google が参照先を、読めない形の転送 URL（`google.com/goto?url=…`）で返すことがあり、その行はどのサイトか分からない。先頭の `references_unknown` が、そういう引用の数。「不明」の行があるとき、自社の引用と順位は「いいえ」ではなく「分からない」と出る。題で見当が付くものは、題で判断したと書く。引用元を数えるときは、「不明」の数を別に記録する。
- `--text` を付けると、AI による概要の本文も出る。自社について何と書かれているかを読むときに使う。概要が出ていない問いでは、その旨の 1 行だけが出る。
- 1 問ごとに料金がかかる。同じ問いを同じ日に引き直さない。
- 検索数が空の長い問いでも、検索結果を取ると、上位が無関係な記事ばかりで入り込める穴のことがある。有望な問いは、検索数が空でも確かめる。
- 「〈AI の製品名〉 〈業務〉」の形は、その製品の中の別の機能のこととして取られていることがある。検索数だけで選ばず、上位と引用元の題で意図を確かめる。
- 引用元に、製品や媒体の**公式の告知**が出たら読む。戦略の前提を変える新しい事実が、ここで見つかることがある。見つけたら、戦略の見直しとして人間に報告する。
- `ai_overview` が「なし」のときは、その問いでは概要が出ていない。引用率の分母に入れない。
- パソコンでの検索結果を見ている。スマートフォンでは違うことがある。

## 初めてつないだとき

`--sandbox` を付けると、料金のかからない試験用の場所を呼ぶ。返るのは見本のデータで、形だけ本物と同じ。入金の前でも、アカウントがあれば使える。

```bash
python3 scripts/dataforseo.py --sandbox balance
python3 scripts/dataforseo.py --sandbox volume "test"
python3 scripts/dataforseo.py --sandbox serp "test"
```

3 つともエラーなく表が出れば、つながっている。`balance` だけ通って残りが `HTTP 403` なら、鍵は正しく、アカウントの確認が残っている。

試験用の場所は、渡した語と関係のない見本を返す。確かめられるのは「つながるか」と「出力の形」だけで、`--own` の判定や `--text` の中身は確かめられない。見本のデータを、本物の数字として記録しない。

## エラー

| 状態 | 意味 |
|---|---|
| `HTTP 401` | ログインかパスワードが違う。管理画面の「API Access」にある API 用のパスワードを使う（サイトに入るときのパスワードとは別） |
| `HTTP 403`（コード 40104） | アカウントの確認が済んでいない。管理画面でメールアドレスと電話番号の確認を済ませてもらう。`balance` だけは確認の前でも通る |
| `HTTP 402`、または残高についての知らせ | 残高不足。やり直しても直らない |
| `HTTP 429` | 呼び出しが多すぎる。1 分待つ |
